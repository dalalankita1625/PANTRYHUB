# 🛒 PantryHub – Online Grocery Shopping Platform

## About the Project

PantryHub is a full-stack online grocery shopping platform designed to make purchasing fresh groceries and vegetables easier and more convenient. The application focuses on providing a simple shopping experience through an organized product catalog and user-friendly interface.

## Features

- Online grocery and vegetable shopping.
- Product browsing and organized product listings.
- User-friendly shopping interface.
- Full-stack application with separate frontend and backend.
- Responsive web interface.

## Technologies Used

**Frontend**
- React.js
- TypeScript

**Backend**
- Node.js

**Deployment**
- Vercel (Frontend)
- Render (Backend)
